Use Nightfall over https

Chrome on Android only installs Nightfall as an app from an https:// address. For that, your phone needs to trust this PC. You do this once per phone.

  1. Download this PC's certificate

    Download Nightfall.crt

    It can only vouch for addresses on your home network, so it can't be used to imitate a website.

  2. Install it

    On another phone

  3. Open Nightfall over https

    Checking whether this phone trusts the PC…

    Open Nightfall

    Once it's open, Chrome's menu › Add to Home screen › Install puts it on your Home Screen as an app.
